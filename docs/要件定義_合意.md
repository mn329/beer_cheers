合意日: 2026-09-17

---

## 一言

オンライン飲み会の「乾杯」を、見る体験から、振る・鳴る体験に変える。

---

## 誰のため

離れた友人同士の Zoom 飲み会参加者。

通話（Zoom 等）の代替ではなく、**カメラの横に置く乾杯レイヤ**。

---

## 「Zoom だけでいいじゃん」への答え

1. **演出の同時性** — 相手の乾杯が声・口だけにならず、自分の端末も音・振動・演出で反応する
2. **身体性** — 振るという動作そのものが共有される

補足（差別化の優先順）: 身体性 → 演出の同時性 → 儀式性

---

## 成功モーメント

片方の端末で乾杯すると、**数秒以内**にもう片方でも乾杯演出が起きる。  
厳密な同時演奏は約束しない。「相手も乾杯した」と分かればよい。

---

## MVP（必須）

| ID | 内容 |
|----|------|
| A | ローカル乾杯演出（振る・音・触覚・ビジュアル） |
| B | 共有ルーム（作成・参加）。**ルーム URL を開き、確認後に入室**を含む |
| C | リモート乾杯同期 |
| D | メンバー一覧（誰がいるか + 表示名・絵文字の反映） |
| F | プロフィール（表示名・絵文字） |
| H | Apple Watch（タップ → ペアリング済み iPhone 経由でルーム同期） |

説明・デモの出し方: **まず iPhone の振る＋同期＋メンバー**。Watch は後半の第二幕。

---

## できれば

- E: ホスト／退出・解散の運用強化
- ルーム名の**正確一致**検索
- 最近入った部屋の履歴（方針としては可、必須ではない）

---

## やらない／約束しない

- G: 認証を核の説明・必須条件にしない（**ログインなしで Done**）
- ビデオ／音声チャット機能そのもの
- 乾杯履歴・ランキング・友だち検索／SNS 連携
- 未インストール時の App Store／説明ページ導線（方針メモのみ。Done 外）

---

## 入室・鍵

| 経路 | 挙動 |
|------|------|
| ルーム URL | 鍵になりうる。アプリ起動 → **参加確認** → 入室。この経路ではパスワード不要 |
| ルーム名で参加 | 任意パスワードを有効にできる |
| 検索 | ルーム名の正確一致（できれば） |
| 公開一覧型の探索 | やらない（認証なし前提と相性が悪い） |

---

## 失敗時

- リモート未達は許容する
- ローカル演出は**必ず**出す
- ユーザーに**エラー（未達）表示をする**（黙って失敗しない）

---

## MVP Done（完成条件）

1. 2 台の iPhone が同じルームに入り、片方を振ると数秒以内にもう片方で乾杯演出が起きる
2. 各端末の表示名・絵文字がメンバー一覧に見える
3. ログインなしで 1・2 ができる
4. Watch タップの乾杯が、ペアリング済み iPhone 経由で同ルームに同期される
5. Zoom（または同等の通話）と同時利用しても、乾杯同期が破綻しない（通話アプリ自体は作らない）
6. ルーム URL で開き、確認後に参加できる（インストール済み同士）
