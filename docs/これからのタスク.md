### 5. ローカル演出（作業順 D）※当面は後回し可

- [ ] 誤検知・振りやすさの調整（合意では様子見）

### 6. 認証（G）※ MVP の核ではない／約束しない

合意: **ログインなし（ゲスト）で Done**。Sign in with Apple / Google は任意。メール／パスワードは使わない。核の説明・デモの主役にしない。
サインイン後は **ユーザー名・ニックネーム・プロフィール画像** の3点を必須とする（ゲストは対象外）。
アカウントは下部タブから開く。ヘッダーをタップして **編集 / サインアウト / 削除**。下段の追加 UI は保留（バージョンのみ）。本体利用中のプロフィール設定キャンセル時はアカウントタブへ戻る。

手順: `[docs/social-auth.md](./social-auth.md)` / `[docs/storage-avatar.md](./storage-avatar.md)`
